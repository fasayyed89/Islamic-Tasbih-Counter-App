## 📥 How to Install on Android

1. Download the latest **`IslamicTasbih_V2.apk`** (V2 3D Luxury) or **`IslamicTasbih.apk`** (V1 Classic) from [**Releases**](https://github.com/fasayyed89/Islamic-Tasbih-Counter-App/releases).
2. Tap the downloaded file on your Android phone.
3. If prompted, allow **"Install from unknown sources"** for your browser / file manager:
   - *Settings → Security → Install Unknown Apps → Enable for Chrome/Files*.
4. Tap **Install** and enjoy your Dhikr experience!

## 🍎 For iPhone (iOS) Users

Use the **Official Web App / PWA version** directly on your iPhone with offline capabilities:

1. Open [**https://fasayyed89.github.io/Islamic-Tasbih-Counter-App/**](https://fasayyed89.github.io/Islamic-Tasbih-Counter-App/) in **Safari**.
2. Tap the **Share button** (the square with an arrow pointing up at the bottom).
3. Scroll down and tap **"Add to Home Screen"**.
4. The Islamic Tasbih icon will appear on your iPhone home screen and launch like a native full-screen app!
