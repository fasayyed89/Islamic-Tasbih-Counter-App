## 📥 How to Install on Android

1. Download the latest **`IslamicTasbih.apk`** from [**Releases**](https://github.com/fasayyed89/Islamic-Tasbih-Counter-App/releases/latest/download/IslamicTasbih.apk).
2. Tap the downloaded file on your Android phone.
3. If prompted, allow **"Install from unknown sources"** for your browser / file manager:
   - *Settings → Security → Install Unknown Apps → Enable for Chrome/Files*.
4. Tap **Install** and start your Dhikr journey!

## 🍎 For iPhone (iOS) Users

While native APK files cannot run directly on iOS without the App Store, you can use the **Official Web App / PWA version** directly on your iPhone with full offline capabilities:

1. Open [**https://fasayyed89.github.io/Islamic-Tasbih-Counter-App/**](https://fasayyed89.github.io/Islamic-Tasbih-Counter-App/) in **Safari**.
2. Tap the **Share button** (the square with an arrow pointing up at the bottom).
3. Scroll down and tap **"Add to Home Screen"**.
4. The Islamic Tasbih icon will appear on your iPhone home screen and launch like a native full-screen app!

## 🛠️ Tech Stack & Architecture

- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose with Material 3 Design
- **Navigation**: Navigation3 Architecture
- **State Management**: Kotlin StateFlow & Coroutines
- **Storage**: SharedPreferences with thread-safe formatting
- **Audio Engine**: PCM Synthetic Waveform AudioTrack
- **Graphics**: Custom Vector Drawables & Canvas Particle Simulation
- **Minification**: R8 Full ProGuard Minification + Resource Shrinking
